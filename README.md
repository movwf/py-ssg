# Static Site Generator (SSG)

A tiny, educational static site generator written in Python. It takes a directory of Markdown files, converts them to HTML using a simple template, and copies static assets into a `public/` folder ready to be served.

## Features

- **Markdown → HTML** conversion using a custom parser (`markdown_to_html_node`).
- **Title extraction** (`utils.extract_title`) for automatic `<title>` tags.
- **Recursive page generation** – all `.md` files in the `content/` tree are turned into matching `.html` files while preserving the directory structure.
- **Static assets** (`static/`) are copied verbatim to `public/`.
- Simple development server via `main.sh` (`python3 -m http.server 8888`).

## Getting Started

1. **Prerequisites**
   - Python 3.12+ (the code uses f‑strings and type hints).
   - No external dependencies – everything lives in the `src/` package.

2. **Clone the repo** (if you haven't already):
   ```bash
   git clone <repo-url>
   cd ssg
   ```

3. **Run the generator**
   ```bash
   bash main.sh
   ```
   This will:
   - Remove any existing `public/` directory.
   - Copy static assets.
   - Recursively generate HTML pages from `content/`.
   - Start a development server on `http://localhost:8888`.

4. **Open the site**
   Navigate to `http://localhost:8888` in your browser. All generated pages (e.g., `index.html`, `blog/glorfindel/index.html`, `contact/index.html`) are accessible via relative links.

## Adding New Content

- Place a new Markdown file anywhere under `content/`.
- Use standard Markdown syntax. The first level‑1 heading (`# Title`) will become the page title.
- Run `bash main.sh` again to rebuild the site.

## Customising the Template

Edit `template.html` – the only placeholders are:

- `{{ Title }}` – replaced with the extracted H1 text.
- `{{ Content }}` – replaced with the generated HTML for the Markdown file.

Feel free to add CSS, meta tags, or any additional markup.

## Testing

Unit tests live in the `src/` directory (e.g., `test_extract_title.py`). Run them with:
```bash
pytest -q
```
